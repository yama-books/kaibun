# v0.18 汎用 sentence wrapper

## 基本式

既存の完全回文文を P とする。

`LEFT + P + reverse(LEFT)`

LEFT / RIGHT を日本語として別の意味に読ませる。

### 登録wrapper

- 大樹と「P」と聞いた。
  - LEFT: たいきと
  - RIGHT: ときいた

- タミと「P」と見た。
  - LEFT: たみと
  - RIGHT: とみた

- ルミと「P」と見る。
  - LEFT: るみと
  - RIGHT: とみる

- 対価と「P」と書いた。
  - LEFT: たいかと
  - RIGHT: とかいた

## 性質

Pが完全回文なら、wrapper後も必ず完全回文。

そのため完成文を事前登録する必要がない。

例:
- 妻が待つ。
- 大樹と「妻が待つ」と聞いた。
- タミと『大樹と「妻が待つ」と聞いた』と見た。
- ルミと「タミと『大樹と「妻が待つ」と聞いた』と見た」と見る。

と、文そのものを外側へ無制限に伸ばせる。

## 品質

構文成立は保証しやすい一方、入れ子が深くなるほど読みやすさは落ちる。

- depth 0: 元文
- depth 1〜2: L2の通常域
- depth 3〜5: 怪文度5
- depth 6以上: 長文実験域

UIではwrap depthとかな長を表示し、1段ずつ包む／ほどく操作にする。


## v0.19 追加wrapper

### 理由化

`だいせの + P + のせいだ`

表示:
> ダイセの「P」のせいだ。

内側の文を「発言・文言」として引用名詞化し、それを原因として扱う。

### 記録・同定

`だんなきろくの + P + のくろきなんだ`

表示:
> 旦那、記録の「P」の黒木なんだ。

内側の文を記録タイトル／記録文言として扱い、「その記録の黒木」という名詞句へ変換する。

この2種は意味上の怪しさが強いため、それぞれ怪文度下限4・5を持つ。
