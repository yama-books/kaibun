# v0.21 主題型 sentence wrapper

## 目的

「Xと『P』とV」型だけでは、外側の人物と引用内容の関係が読みにくい場合がある。

そこで

`Xは + P + はV`

を追加する。

例:
- ウイは「P」は言う。
- 大樹は「P」は聞いた。
- 田部野は「P」は述べた。
- ウトは「P」は問う。
- ルタカは「P」は語る。
- タメキは「P」は決めた。
- タミは「P」は見た。
- ルミは「P」は見る。
- タイカは「P」は書いた。
- 久木は「P」は聞く。
- ルシは「P」は知る。

同じ読みの外側名詞を使う companion 型と topic 型は、衝突判定では同一語とみなす。
したがって一度「大樹」を使えば、大樹の別wrapperも以後候補から消える。

- distinct outer readings: 15
