# v0.12 物語型の段階長文化

## ねらい

親族語の再帰だけでは「文字数」は増えても、文章の情報が増えにくい。

そこで、物語型では各段階に **何を追加したか** を明示する。

### 松茸系

1. 松茸摘み、見つけた妻。  
   追加情報: 出来事の核
2. 松茸摘みに来て、奇跡的に見つけた妻。  
   追加情報: 経緯・評価
3. この松茸摘みに来て、奇跡的に見つけた妻の子。  
   追加情報: 人物関係
4. 確かに、この松茸摘みに来て、奇跡的に見つけた妻の子に貸した。  
   追加情報: 行為

### 場所つきの例

- 庭のワニ。
- この庭のワニの子。
- 確かに、この庭のワニの子に貸した。

- 店のセミ。
- この店のセミの子。
- 確かに、この店のセミの子に貸した。

## 品質方針

物語型は一般規則で無制限に組み合わせない。まず全文を個別監査し、

- 日本語として読める
- 前段の意味をなるべく保持する
- 新しい情報が1種類増える
- かな表記で完全回文
- 必ず前段より長い

ものだけ登録する。

現在 8 family / 25 stage を登録。
