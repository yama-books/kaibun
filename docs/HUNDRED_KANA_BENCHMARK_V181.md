# v0.18.1 100かな級ベンチマーク

汎用sentence wrapperは任意回数利用できるが、品質管理用に固定の長文ベンチマークも保持する。

基礎:
- 松茸系 51かな

引用・伝聞wrapperを段階的に追加:
- 59かな
- 67かな
- 75かな
- 83かな
- 87かな（既存登録系列）
- 95かな
- **99かな**

最終文は意味的にはかなり入れ子だが、

1. 各外枠が日本語の引用・判断構文として解析可能
2. 内側の文を一切変更しない
3. 全体が完全回文
4. 各stageで必ず長くなる

ことを自動検証する。

100かな級はL2怪文度5の実験域とし、L1の自然文基準とは分離する。
