# v0.32 歴史回文短歌の意味場

## 方針

歴史作例の自然さを「逆読みにしやすい語」だけで説明しない。

先に一つの意味場を作り、その中の語彙で回文制約を吸収する。

## 50首の暫定分類

- 春・草木: 12首
- 秋・月: 12首
- 信仰: 8首
- 恋・人事: 6首
- その他: 4首
- 冬・雪: 4首
- 夏・行事: 4首

mining層40首は、山内翻刻に付された題だけを根拠に分類した。
本文の意味解釈はまだ確定しない。

## 生成器への反映

1. 意味場を選ぶ
2. その意味場の語彙だけを優先
3. 31かなの鏡像格子を満たす
4. 中央3かなABAを意味ピボットとして探索
5. 左右で異なる形態素境界を許す
6. 全文の景・出来事として自然かで採否

これは「逆語ペアを先に選び、あとから意味を付ける」方式の逆。
