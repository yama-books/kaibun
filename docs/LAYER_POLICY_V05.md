# コーパス階層設計 v0.5

## 目的

回文として成立することより先に、**日本語としての質を階層化**する。

### L1 第一層: 標準日本語
- 助詞・活用・語順を含め、通常の独立文として自然
- 多少の主語・目的語省略は、日本語の通常の省略として許容
- 生成器の主なDNAはここから取る
- 現在 61件

新しく有効だった生成型:
- 私が + 1文字中心 + がしたわ  
  例: 私が探したわ / 流したわ / 剥がしたわ
- 私も + 1文字中心 + もしたわ  
  例: 私もメモしたわ / デモしたわ
- よく + 1文字中心 + くよ  
  例: よく聞くよ / 泣くよ / 書くよ
- 夜 + 1文字中心 + るよ  
  例: 夜、寝るよ / 見るよ / 来るよ

これらは文字上の鏡面と語境界が一致しないため、単純な回文語の数珠つなぎになりにくい。

### L2 第二層: 意味の通る怪文
- 文法・意味関係は追える
- 口語省略や奇妙な意味関係を許す
- 例: 旦那、キキなんだ。 / 確かに、庭のワニに貸した。
- 現在 22件

### L3 第三層: 実験文
- 電文調・舞台指示・見出し風
- 例: タミ、母見た。 / ルミ、母見る。
- 標準生成には混ぜない
- 現在 83件

## v0.3からの扱い
- 日本語の骨格が崩れていた875件は標準土台から除外
- L3候補は破棄せず実験用に保存
- 今後1000件へ戻す際は、L1の**構文型の種類**を増やすことを優先し、同一型の語彙置換だけで水増ししない
