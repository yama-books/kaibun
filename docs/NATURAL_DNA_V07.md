# v0.7 自然文DNA拡張

## 発見

日本語の回文生成では、**名詞の読みを逆にすると自然な動詞・形容詞になるペア**が非常に強い。

例:
- 妻 / 待つ
- 須田 / 出す
- タミ / 見た
- ルミ / 見る
- ルネ / 寝る
- タキ / 来た
- タキオ / 起きた
- ルイ / いる
- 鯛 / いた
- 靴 / つく
- イルカ / 軽い
- 椅子屋 / 安い
- 井川 / 若い
- 竹屋 / 焼けた
- 蓼 / 出た

この間に1文字の助詞を置けば、文字列全体は回文のまま、日本語の格関係を明示できる。

例:
- 妻が待つ。
- 妻を待つ。
- タミが見た。
- ルミを見る。
- ルイがいる。
- 靴に付く。
- 靴を突く。
- イルカが軽い。

## 長文化

さらに助詞「も」「と」を鏡面側にも置くと、中心へ自己回文の人物名詞を挿入できる。

- 妻も母も待つ。
- タミも母も見た。
- ルイも父もいる。
- 妻とナナと待つ。

これは「単語を数珠つなぎにした回文」ではなく、**日本語の統語構造そのものが鏡になる**ため、今後の主力DNAとする。
