# v0.25 宝船回文歌から学ぶ「境界ずらし」

## 1. 歴史上の位置づけ

「長き夜の…」は江戸時代の宝船・初夢習俗で著名になった回文歌だが、江戸時代に新作されたと断定するのは適切ではない。

国立国会図書館レファレンス協同データベースでは、成立時期は不明としつつ、1592年刊の中国の日本研究書『日本風土記』に「琴譜廻文詞」として載ることを確認している。参照資料には1548年成立『運歩色葉集』も古い文献として挙げられる。

したがって本プロジェクトでは **「江戸の宝船習俗で広く親しまれた、少なくとも16世紀まで遡る著名な回文歌」** と扱う。

## 2. 回文としての正規化

```
なかきよの とをのねふりの みなめさめ なみのりふねの をとのよきかな
```

空白を除くと31かなで完全回文。

歴史的な回文には清濁・オ/ヲなど音韻上の同一視を許す伝統がある。現行アプリの通常モードは現代かなの厳密一致を維持し、古典資料は研究用の別normalizationとして扱う。

## 3. 最重要の発見

この歌の巧さは **語を一対一で反転していないこと** にある。

### 皆 ↔ 波

`みな + めさめ + なみ`

- 皆 = 「目覚め」の主語
- 波 = 次の「波乗り舟」の先頭
- 中央の「目覚め」は自己回文

鏡像する語が同じ統語役割を持っていない。

### 遠 ↔ 音

`とを` ↔ `をと`

別の名詞同士を逆読みに利用する。

### 眠り ↔ 乗り舟

`ねふり` の逆は `りふね`。

しかし「り舟」という語を無理に作らず、隣の `の` と境界をずらして

`の + りふね → のりふね（乗り舟）`

と再分節する。

### 長き夜 ↔ 良きかな

`なかきよ` ↔ `よきかな`

左は名詞句、右は評価的な終止。品詞構造が一致しない。

## 4. v0.25 の生成原理

従来:
> LEFT phrase ↔ reverse(LEFT phrase)

v0.25:
> **かな列だけ鏡像。語境界は完成した日本語に合わせて後から切る。**

実装上は「殻 shell」と「核 core」に分ける。

例:

```
core: の
庭 + の + ワニ
この + 庭のワニ + の子
に + この庭のワニの子 + に
確か + にこの庭のワニの子に + 貸した
```

完成:
> 確かにこの庭のワニの子に貸した。

ここでは
- 庭 ↔ ワニ
- この ↔ の子
- 確か ↔ 貸した
- 「に」「の」は文法ヒンジ

であり、左右の品詞や形態素境界は一致していない。

## 5. 今後の評価

長文候補には「非ラッパー性」を評価する。

高評価:
- 鏡像する語が別の統語役割を持つ
- 形態素境界が左右でずれる
- 助詞が境界を自然に接続する
- 中央に意味のあるピボットがある
- 全文で意味が通る

低評価:
- X + 引用文 + reverse(X) を何層も重ねただけ
- 同じ名詞や同じ構文が外側で反復する
- 左右の部品境界が完全に一致し続ける

この評価を今後の主生成器へ移す。
