# 生成空間統計 v0.9

原種・DNA規則・再帰DNA・逆語ペア辞書をすべて最大深度まで展開し、**かな読み完全一致で重複除去**した。

- 異なる回文読み: **1,465**

重複例:
- 「妻が待つ。」: 原種 / 旧DNA / 逆語ペア
- 「タミが見た。」: 原種 / 旧DNA / 逆語ペア
- 「確かに、母に貸した。」: 原種 /旧DNA / 再帰DNA

## UI方針

同じ読みは生成経路が何本あっても1候補として扱う。

これにより、
- 良質な古い文だけが過剰に出るバイアスを防ぐ
- 「押しても同じものが出る」問題を抑える
- 実際の多様性を候補数として表示できる

という効果を得る。

公開UIでは、現在選択中の層・怪文度・長文化深度に応じて「実効候補 ○種」を動的に表示する。
