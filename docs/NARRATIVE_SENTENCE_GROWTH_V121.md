# v0.12.1 物語型を全文方式へ修正

物語型の途中段階が「子猫。」「この子猫の子。」のような名詞句になっていたため、全段階を文として成立させた。

## 基本形

- 確かに貸した。
- 確かに、子猫に貸した。
- 確かに、この子猫の子に貸した。

毎段階で述語「貸した」を保持し、情報だけを追加する。

## 松茸系

- 確かに貸した。
- 確かに、松茸摘み、見つけた妻に貸した。
- 確かに、松茸摘みに来て、奇跡的に見つけた妻に貸した。
- 確かに、この松茸摘みに来て、奇跡的に見つけた妻の子に貸した。

追加される情報は「相手 → 経緯・評価 → 人物関係」。

## 場所系

- 確かに貸した。
- 確かに、庭のワニに貸した。
- 確かに、この庭のワニの子に貸した。

「庭」が場所情報として追加され、その後に関係情報が加わる。

全25段階を完全回文・文字数単調増加で検証。
