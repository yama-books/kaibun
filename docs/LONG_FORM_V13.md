# v0.13 50文字級への段階長文化

物語型の最終文をさらに伸ばすため、受け手の名詞句を鏡型の親族関係で包む。

## 松茸系

前半:
1. 確かに貸した。
2. 確かに、松茸摘み、見つけた妻に貸した。
3. 確かに、松茸摘みに来て、奇跡的に見つけた妻に貸した。
4. 確かに、この松茸摘みに来て、奇跡的に見つけた妻の子に貸した。

後半:
5. 確かに、母のこの松茸摘みに来て、奇跡的に見つけた妻の子の母に貸した。
6. 確かに、父の母のこの松茸摘みに来て、奇跡的に見つけた妻の子の母の父に貸した。
7. 確かに、母の父の母のこの松茸摘みに来て、奇跡的に見つけた妻の子の母の父の母に貸した。

最長読みは **51かな**。

## 性質

- 述語「貸した」は最後まで固定。
- 相手の中心情報も保持。
- 1段ごとに親族関係が1層増える。
- 日本語の統語構造は維持。
- 意味の奇妙さだけが段階的に増える。
- 全段階で完全回文・文字数単調増加を検証。

これは「長くするために回文語を並べる」のではなく、ひとつの名詞句を文法的に深くする方式。
