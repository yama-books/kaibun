# v0.34 31かな回文短歌の5変数文法

## 基本式

31かなを韻律境界と鏡像境界の両方で切る。

```
A₅ | B₂ | C₅ | D₂ | E₃ | Dᴿ₂ | Cᴿ₅ | Bᴿ₂ | Aᴿ₅
```

五句は

```
5  = A
7  = B + C
5  = D + E
7  = Dᴿ + Cᴿ
7  = Bᴿ + Aᴿ
```

となる。

## 意味

生成時に独立に考える必要があるのは、実質

- A: 5かな
- B: 2かな
- C: 5かな
- D: 2かな
- E: 3かな（ABA）

だけ。

残りは鏡像で決まる。

ただし重要なのは、**部品そのものを日本語単位と見なさないこと**。

B+C は一つの7かな句として読み、
反転側の Dᴿ+Cᴿ ではまったく別の語境界を許す。

## 宝船歌に当てはめる意義

「眠り → のり舟」のような境界ずらしを偶発的処理ではなく、
この格子上の別解析として扱える。

## 生成器

A/B/C/D/E の文字列を作る生成器ではなく、

1. 第一句Aが自然
2. 第二句B+Cが自然
3. 第三句D+Eが自然
4. 第四句Dᴿ+Cᴿが自然
5. 第五句Bᴿ+Aᴿが自然

を同時に満たす制約充足問題として解く。

さらに5句が同じ意味場に属することを必須に近い強さで評価する。

## 50首検証

現在の信頼済み10首＋採掘40首は、すべてこの分解式に完全一致した。
