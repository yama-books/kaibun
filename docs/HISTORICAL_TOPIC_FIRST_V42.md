# v0.42 題を先に選ぶ

山内潤三は、廻文歌が強い制約を持ちながらも、題材としては伝統的和歌世界へ追随すると論じている。

したがって生成器も、

`回文になる音 → 意味を付ける`

ではなく、

`題 → 意味場 → 句候補 → 31かな制約`

の順へ変える。

## 優先題

### 秋・月
歴史コーパスでも量が多く、現在の有望交配候補もこの群から出ている。

### 春・草木
梅・桜・若草・七草・霞など、相互に一枚の景を作りやすい。

### 神祇・釈教
「水↔罪」のような意味転換が題の中で機能しやすい。

## 評価の最優先

五句を別々に自然にするだけでなく、
**一首を読んだとき同じ場所・季節・時間・出来事を見ているか**を最重要にする。

歴史作の自然さは、逆読みに成功した語彙の数より、
意味場を最後まで維持したことにある。
