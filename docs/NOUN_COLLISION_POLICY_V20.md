# v0.20 セリフ内外の名詞重複回避

## 方針

文レベルwrapperでは、外側に置く名詞が内側の引用文にすでに存在する場合、そのwrapperを使わない。

例:
- 内側に「タミ」がある → 「タミと『…』と見た」は候補から外す
- すでに外側で「大樹」を使った → 次段階では大樹系wrapperを外す

判定は display と reading の両方で行う。

## wrapper語彙

現在 11種類。

- 発言: ウイと「P」と言う。 / 外側語彙: ウイ
- 伝聞: 大樹と「P」と聞いた。 / 外側語彙: 大樹
- 陳述: 田部野と「P」と述べた。 / 外側語彙: 田部野
- 質問: ウトと「P」と問う。 / 外側語彙: ウト
- 語り: ルタカと「P」と語る。 / 外側語彙: ルタカ
- 決定: タメキと「P」と決めた。 / 外側語彙: タメキ
- 判断: タミと「P」と見た。 / 外側語彙: タミ
- 解釈: ルミと「P」と見る。 / 外側語彙: ルミ
- 記述: 対価と「P」と書いた。 / 外側語彙: 対価
- 理由化: ダイセの「P」のせいだ。 / 外側語彙: ダイセ
- 記録・同定: 旦那、記録の「P」の黒木なんだ。 / 外側語彙: 旦那・記録・黒木

## 固定長文

既存の引用長文4系統もこの規則で再生成した。
同じ外側名詞の再登場を禁止し、最長固定例は **131かな**。

100かな基準:
- family: quote-matsutake
- length: **131かな**
- outer noun collision: 0
