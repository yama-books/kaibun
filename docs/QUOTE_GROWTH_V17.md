# v0.17 引用・伝聞による文レベル長文化

## 発見

既存の完全回文文 P に対し、次の左右ペアを使う。

- `たいきと` / `ときいた` → 大樹と「P」と聞いた。
- `たみと` / `とみた` → タミと「P」と見た。
- `るみと` / `とみる` → ルミと「P」と見る。
- `たいかと` / `とかいた` → 対価と「P」と書いた。

左右は互いに逆読みなので、Pが回文なら新しい全文も必ず回文になる。

## 重要性

これまでの長文化は主に名詞句内部を深くしていた。
v0.17では**文全体を引用節にして新しい主節を外側へ追加**する。

つまり、

- 名詞句の長文化
- 文レベルの長文化

を分離して扱える。

## 長さ

5段の文レベルwrapperを用意。

主な最終長:
- 引用：松茸の長文を伝聞する: 87かな
- 引用：庭のワニを伝聞する: 77かな
- 引用：理由を伝聞する: 65かな
- 引用：待つ出来事を伝聞する: 60かな

最長は **87かな**。

## 品質

深くなるほど引用が入れ子になるためL2で扱う。
最初の1〜2層は比較的追いやすく、3層以降は怪文度5の長文実験域とする。
