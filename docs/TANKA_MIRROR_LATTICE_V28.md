# v0.28 回文短歌の鏡像格子

## 1. 31かなと5-7-5-7-7は対称ではない

短歌の句切れは

- 5
- 12
- 17
- 24

かな目の後。

31かなの回文として反転すると、それぞれ

- 26
- 19
- 14
- 7

かな目の後へ写る。

元の句切れと一致するものは一つもない。

## 2. 両方の境界を重ねる

境界を昇順に並べると

`5 / 7 / 12 / 14 / 17 / 19 / 24 / 26`

したがってセル長は

**5 / 2 / 5 / 2 / 3 / 2 / 5 / 2 / 5**

となる。

この列自体が左右対称。

## 3. 何が分かるか

回文短歌では、韻律の句境界と回文上の鏡像境界が**構造的に必ずずれる**。

したがって、

- 「眠り」→「（の）り舟」
- 一句目の語が五句目の途中へ食い込む
- 第二句の鏡像が四句＋五句を跨ぐ

といった再分節は、特殊な裏技ではなく形式の中核にある。

## 4. 生成器への示唆

従来のように

> 左の文節を決める → 右に逆文節を置く

では短歌型へ近づきにくい。

代わりに、

1. 31かなの対称音列を作る
2. 5-7-5-7-7の切れ目を後から置く
3. 鏡像句境界 7/14/19/26 も保持する
4. 5-2-5-2-3-2-5-2-5 の継ぎ目格子を跨いで語を再分節する
5. 左右で異なる形態素解析を許す
6. 最後に全文の意味と韻律で選ぶ

という順序がよい。

## 5. 山内論文からの大規模採掘

山内潤三「廻文歌の限界と効用（下）」は『廻文歌百首』『廻文百よくるま』を翻刻し、両書合計303首の語彙を研究している。

これは今後、

- 初句↔第五句の語彙
- 逆読みによる別語化
- 助詞ヒンジ
- 中央5かなの機能
- 季語・景物の意味場

を数量化するための主資料にする。

## 6. 今回の採掘

翻刻から31かな完全回文として機械確認できた10首を、信頼済みコーパスとは別の mining queue に追加した。

漢字復元・意味解釈はまだ確定せず、まず**音列データとして保全**する。
