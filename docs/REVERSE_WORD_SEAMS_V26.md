# v0.26 逆読みによる別語化

宝船回文歌の
- 遠 ↔ 音
- 皆 ↔ 波

に近い仕組みを現代語側で増やす。

## 追加した主な語彙対

- 記録（きろく）↔ 黒木（くろき）
- 池（いけ）↔ ケイ（けい）
- 山（やま）↔ マヤ（まや）
- 川（かわ）↔ ワカ（わか）
- 海（うみ）↔ ミウ（みう）
- 家（いえ）↔ エイ（えい）
- 梨（なし）↔ 品（しな）
- イカ（いか）↔ 会（かい）
- 砂（すな）↔ ナス（なす）
- リス（りす）↔ スリ（すり）
- 嘘（うそ）↔ 層（そう）
- 声（こえ）↔ エコ（えこ）

重要なのは、これらを単独で「回文語ペア」と見せないこと。

中央の「の」を使って

- 記録の黒木
- 池のケイ
- 山のマヤ
- 川のワカ
- 海のミウ
- 家のエイ
- 梨の品

のような普通の名詞句にする。

さらに全文では

- タミも記録の黒木も見た。
- 確かに池のケイに貸した。
- ダイセの山のマヤのせいだ。
- 旦那、海のミウなんだ。

のように埋め込む。

## 評価方針

「鏡の左と右が同じ文法部品」より、

- 左右で意味が変わる
- 役割が変わる
- 助詞を挟むと一つの自然な句になる
- 全文では回文技巧が目立ちすぎない

ものを優先する。
