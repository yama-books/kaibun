# v0.9 逆語ペア辞書

## 目的

個別の回文規則を増やし続けるのではなく、最も成功率の高い構造をデータベース化する。

### 基本式

`LEFT + 助詞 + reverse(LEFT)`

LEFT を名詞・固有名詞、reverse(LEFT) を自然な動詞・形容詞として読める場合、一文字の助詞を鏡面中心に置ける。

例:
- 妻 + が + 待つ
- 妻 + を + 待つ
- タミ + が + 見た
- ルミ + を + 見る
- 魚 + を + 追う
- 大使 + が + 敷いた
- タイヤ + を + 焼いた
- ダンス + が + 済んだ

### 品質管理

重要なのは、回文になる助詞を全部許可しないこと。

たとえば「妻に待つ」は文字列上は回文でも現代日本語として不自然なので登録しない。
「靴をつく」は読みだけなら成立するが、表記は「靴を突く」と解釈して初めて自然になるため、variant側で述語表記を上書きする。

つまり **回文条件はアルゴリズム、助詞選択は日本語文法のホワイトリスト** とする。
