# v0.38 回文歌cento

## 発見

v0.35の因子グラフ交配では、生成された31かなの五句がすべて既存歴史作に由来する。

- 第一句 A: ABを持つ原歌
- 第二句 B+C: BCを持つ原歌
- 第三句 D+E: DEを持つ原歌
- 第四句 Dᴿ+Cᴿ: CDを持つ原歌
- 第五句 Bᴿ+Aᴿ: ABを持つ原歌

したがって「文字断片を継いだ」のではなく、
**歴史上実在した5/7/5/7/7の句を、鏡像格子の互換点で組み替えた新しい回文短歌**とみなせる。

## 研究上の扱い

本歌取りそのものではないため、当面「historical palindrome tanka cento」と呼ぶ。

採用条件:
1. 同じ大意味場
2. 継ぎ目署名が互換
3. 可能なら元作品間に共有意味タグ
4. 全文意味を人手確認

歴史句の出典は候補ごとに保持する。
