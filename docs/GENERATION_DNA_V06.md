# 生成DNA設計 v0.6

## 方針

v0.6 では、第一層 L1 を単なる例文集ではなく、**日本語として自然な文を再生産できるDNA規則**として管理する。

- 自由な1文字代入はしない。
- 各スロットは人間が意味・文法を確認したホワイトリスト。
- L1 は独立した普通の日本語文として読めることを優先。
- 文法は正しいが口語省略や意味上の異常が強いものは L2。
- 電文調・舞台指示調は L3。

## v0.6 の規則

計 **26規則**。

主要な新規生産型:
- 私、Cしたわ。 → 私、貸したわ / 消したわ / 押したわ / 出したわ
- 私、まCましたわ。 → 私、混ぜましたわ / 待ちましたわ / 曲げましたわ
- かCか → 買うか / 貸すか / 書くか / 勝つか
- なCな → 泣くな / 鳴るな
- よCよ → 読むよ / 寄るよ / 呼ぶよ
- ねCね → 寝るね / 寝たね
- のCの → 飲むの / 乗るの
- わCわ → 沸くわ / 割るわ
- なかCかな → 仲間かな / 中身かな / 中井かな

文字列の鏡面と、単語・助詞・活用の境界が別位置に来る規則を優先している。
