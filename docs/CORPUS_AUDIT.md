# 回文原種コーパス一次監査 v0.4

v0.3 の1000件を、回文成立ではなく **日本語としての自然さ** を優先して規則単位で監査した。

## 結果
- 元データ: 1000件
- 自動採用: **36件**
- 方針裁定待ち: **89件**
- 低怪文度の原種から除外: **875件**

1000件を人手で1件ずつ読む必要はない。生成規則が共通するため、不自然さも規則単位で反復している。

## 自動除外した系統
- 二重「は」型: 396件  
  例: 「タミは、母は見た。」  
  単独文では対比文脈を要求し、自然な基準文にならない。
- 強制的なコピュラ同定型: 98件  
  例: 「旦那、母なんだ。」  
  意味関係が回文都合で固定され、原種として不安定。
- 強制的な「の」連鎖・指示詞連鎖型: 381件  
  例: 「山の母のマヤ」「庭の桃のワニ」「この母の子」  
  文法的に解析できても、意味関係が薄い、または指示詞の係り先が不自然。

## 自動採用した系統
36件。
1. 「確かに、Xに貸した。」型 21件  
   相手が動物でも、誰が何をしたかという意味関係は明瞭。動物相手は怪文度を上げて扱う。
2. 文章型・基準回文 15件。

## ユーザー裁定が必要なのは2点
### D01 助詞省略の電文・会話調
61件。例: 「タミ、母見た。」「須田、桃出す。」「妻、母待つ。」
意味は取れるが、標準的な書き言葉ではない。  
**提案:** 標準原種から外し、「電文調」タグで温存。

### D02 助詞省略＋非過去形
28件。例: 「ルミ、母見る。」
舞台指示やメモとしては成立する。  
**提案:** 標準原種から外し、将来の「舞台指示／メモ調」モード用に温存。

## 次の設計方針
数を1000に保つことを目的化せず、採用36件を「意味の通るDNA」として扱い、新しい自然な構文型そのものを増やす。1000件へ戻すときは、同じ構文の語彙差し替えだけで水増ししない。
