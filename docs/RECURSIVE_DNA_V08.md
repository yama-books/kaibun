# v0.8.1 再帰的長文化

## 品質修正

初版v0.8では「母の母の母の母…」のように、文法上は読めても数珠つなぎ感の強い系統が残った。

v0.8.1では次の制約を加えた。

1. 基礎名詞句に「母の母」「父の父」「子の子」を追加する。
2. 再帰ラッパーは、内側の最外縁と同じ親族語を連続させない。
3. 深度が上がるほど怪文度を 1 → 2 → 3 → 4 と上げる。
4. 標準UIの長文化深度は1を既定値とする。

## 親族名詞句

深度0〜3で **90通り**。

例:
- 母
- 母の母
- 母の父の母
- 母の父の父の母
- 父の母の母の父
- 子の父の父の子

## 自然文フレーム

**12種類**。

そのため、再帰DNAだけで

**90 × 12 = 1080通り**

の完全回文文を生成できる。

例:
- 確かに、母の父の母に貸した。
- 妻も母の父の父の母も待つ。
- ルイも父の母の母の父もいる。
- タミと子の父の父の子と見た。

全1080候補は文字列上の回文成立を自動検証する。
