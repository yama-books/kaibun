# v0.8 再帰的長文化

## 目的

「良質な日本語文」を保ったまま、長文候補を機械的に増やす。

## 親族名詞句

母・父・子は、それぞれ読みが自己回文になる。

- 母: はは
- 父: ちち
- 子: こ

これらを

`Xの + 回文名詞句 + のX`

で包むと、親族関係として普通に解釈できる回文名詞句になる。

例:
- 母の父の母
- 父の母の父
- 母の子の母
- 父の母の父の母の父

深度0〜3で **120個** の親族回文名詞句を生成できる。

## 文への組み込み

9個の自然文フレームへ入れる。

- 確かに、{人物}に貸した。
- 妻も{人物}も待つ。
- 妻と{人物}と待つ。
- ルイも{人物}もいる。
- ルイと{人物}といる。
- タミも{人物}も見た。
- ルミも{人物}も見る。
- タキも{人物}も来た。
- タキオも{人物}も起きた。

したがって、現在の再帰DNAだけで **1080通り** の完全回文文を生成できる。

これは完成文を1080件保存するのではなく、120個の名詞句と9フレームの文法規則からその場で生成する。
