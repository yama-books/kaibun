# v0.40 優先10候補の人手言語レビュー

## 結論

もっとも有望なのは **hybrid-008**。

```
なかきよの
きつるもはきの
はにてりて
にはのきはもる
つきのよきかな
```

暫定的には、

> 長き夜の / 来つるも萩の / 葉に照りて / 庭のきはもる / 月の良きかな

と読める。

35番の「萩・葉・庭・月」の景へ、38番の「長き夜」「月の良きかな」を外側から移した形なので、
単なる音列交配より意味連続性が強い。

ただし「きはもる」などの漢字・語義は校訂画像確認前に確定しない。

## 学習

**意味場一致は必要条件だが十分条件ではない。**

次のランキングでは、
- 2作交配を3作交配より優先
- 外側の第一・第五句が独立して明快か
- 中三句が同一原歌由来か
- 継ぎ目署名が高信頼か
を明示的に加点する。
