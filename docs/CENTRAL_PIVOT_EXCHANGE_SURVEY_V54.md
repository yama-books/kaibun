# CENTRAL_PIVOT_EXCHANGE_SURVEY_V54

更新日: 2026-09-19  
研究層: v0.54

## 1. 目的

v0.53 の「同じDを共有する歴史作どうしで中央E3だけを交換する」操作が、
`はに` 専用の偶然かを固定50首全体で調べる。

機械可読版:
- `data/central-pivot-exchange-survey-v54.json`

## 2. 重要な補正

Eだけを交換する場合、
host の A/B/C/D は一切動かない。

したがって、BやCに
「他作品へ持ち出してよいglobal seam signature」が無くても、
**E-only交換の阻害要因とは限らない。**

必要なのは:
- Dがhost/donorの両方で形態的に成立
- donor Eがhost scene/意味役割と両立
- 全文レビュー

これは v35〜v37 の一般crossoverより狭い操作なので、
より局所的な安全条件を適用できる。

## 3. repeated D

固定50首で複数回出るD:

- はに
- みつ
- みな
- すす
- けふ

## 4. はに

sources:
- 白雪 E=もつも / 冬・雪
- 露 E=しけし / 秋・月
- 月 E=てりて / 秋・月

同一broad fieldで新規になる交換:
- 31 → E=てりて = hybrid-019
- 35 → E=しけし = hybrid-016

v0.53で正例候補として整理済み。

冬雪↔秋月の交換はscene mismatch対照群。

## 5. みつ

sources:
- 地水火風空 E=もひも / 信仰
- 釈教 E=のよの / 信仰

D:
- `みつ↔つみ`
- high
- transferable

E交換:
- hybrid-017
- hybrid-002

両方向とも broad field = 信仰。

**はに以外の最重要テスト群。**

## 6. みな

sources:
- 宝船歌 E=めさめ / 夜・夢・舟
- 月明海上鴻鷹渡 E=かりか / 秋・月・海・鳥

Dは high / transferable だが、
sceneが異なる。

生成済み:
- hybrid-033
- hybrid-030

cross-scene control とする。

## 7. すす

sources:
- 納涼 E=かせか / 夏
- 社頭祝 E=かけか / 信仰

D自体も medium / conditional。
sceneも不一致。

低優先のcontrol。

## 8. けふ

sources:
- 月
- 寄琴恋

Dは high / transferable だが、
両方とも E=`のよの`。

交換しても新規readingにならない。

## 9. 結論

E-only交換を研究する価値が高いのは:

1. `はに`
   - 正例候補あり
2. `みつ`
   - 同一信仰sceneで次の検証対象

対照:
- `みな`: Dは強いがscene不一致
- `すす`: Dもsceneも弱い
- `けふ`: E多様性なし
