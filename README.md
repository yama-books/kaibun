# 怪文回文メーカー

AI APIを使わず、回文制約と日本語の構文パターンを組み合わせて「意味は通るのに少し怪しい」回文を生成する試作プロジェクトです。

## v0.8

第一層の自然な日本語を保ったまま、**再帰DNAによる長文化**を追加しました。

- L1: **159原種**
- L2: **30原種**
- L3: **83原種**
- 合計: **272原種**
- DNA: **65規則**
- 再帰親族名詞句: **120通り**
- 自然文フレーム: **9種類**
- 再帰DNAだけで生成可能: **1,080文**
- 全原種・全再帰候補はかな表記で完全回文を機械検証

### 再帰DNA

母・父・子は読み自体が回文です。これを

`Xの + 回文名詞句 + のX`

で包むと、自然な親族名詞句のまま回文性を保てます。

- 母の父の母
- 父の母の父
- 母の子の母
- 父の母の父の母の父

これを自然文フレームへ挿入します。

- 確かに、母の父の母に貸した。
- 妻も母の父の母も待つ。
- ルイも母の母もいる。
- タミも母の子の母も見た。

完成文1,080件を保存しているわけではなく、**120名詞句 × 9文型**からその場で生成します。
