# 怪文回文メーカー

AI APIを使わず、回文制約と日本語の構文パターンを組み合わせて「意味は通るのに少し怪しい」回文を生成する試作プロジェクトです。

## v0.5: 三層コーパス

日本語としての質を先に階層化しました。

- **L1 第一層: 標準日本語 61件**  
  助詞・活用・語順を含め、通常の日本語文として自然であることを最優先。
- **L2 第二層: 意味の通る怪文 22件**  
  「旦那、キキなんだ。」のような口語省略や、「確かに、庭のワニに貸した。」のような意味上の異常を許容。
- **L3 第三層: 実験文 83件**  
  「タミ、母見た。」などの電文調・舞台指示調。標準生成には混ぜない。

v0.3の1000候補のうち、日本語の骨格が先に崩れていた875件は標準土台から除外しました。

### 新しい自然文生成型

- 私が探したわ / 流したわ / 剥がしたわ
- 私もメモしたわ
- よく聞くよ / 泣くよ / 書くよ
- 夜、寝るよ / 見るよ / 来るよ

これらは文字列の鏡面と単語境界がずれるため、回文部品の数珠つなぎになりにくい構造です。
