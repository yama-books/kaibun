# 怪文回文メーカー

AI APIを使わず、回文制約と日本語の構文パターンを組み合わせて「意味は通るのに少し怪しい」回文を生成する試作プロジェクトです。

- L3: **83原種**

### 再帰DNA

母・父・子は読み自体が回文です。これを

`Xの + 回文名詞句 + のX`

で包むと、自然な親族名詞句のまま回文性を保てます。

- 母の父の母
- 父の母の父
- 母の子の母
- 父の母の父の母の父

これを自然文フレームへ挿入します。

- 確かに、母の父の母に貸した。
- 妻も母の父の母も待つ。
- ルイも母の母もいる。
- タミも母の子の母も見た。

完成文1,080件を保存しているわけではなく、**90名詞句 × 12文型**からその場で生成します。

### v0.8.1 品質制約

「母の母の母…」のような単調な反復を避けるため、同じ親族語を再帰の外縁で連続させない制約を追加しました。標準の長文化深度も2から1へ下げ、深い系統は怪文度を上げたときだけ出やすくしています。


## v0.9 逆語ペア辞書

自然文DNAの中核を `data/reverse-lexeme-pairs-v09.json` に分離しました。

基本形は **LEFT + 一文字助詞 + reverse(LEFT)** です。ただし、回文になる助詞を機械的に全部使うのではなく、日本語として自然な助詞だけをホワイトリスト登録します。

現在:
- 逆語ペア 30組
- 検証済み助詞バリアント 103文

例:
- 妻が待つ / 妻を待つ
- 魚が追う / 魚を追う
- 大使が敷いた
- 大佐が裂いた
- タイヤを焼いた
- タイツが付いた
- 対価を書いた
- ダンスが済んだ

公開UIには「逆語ペア」ボタンを追加しました。


### 実効生成空間

最大深度まで展開して読みで重複除去すると、現在 **1,465種類**の異なる回文を生成できます。

- L1: 1,334
- L2: 48
- L3: 83

同じ文が複数の生成経路に存在する場合は、公開UIで1候補に統合して出現確率の偏りを防ぎます。


## v0.10 段階的長文化

従来の「長文DNA」は指定深度以下を全部混ぜて抽選していたため、長文化を指定しても短文が出る問題がありました。

v0.10では長文化を独立した成長操作に変更しました。

- 短文から開始
- 1段伸ばす
- 同じ段階で別案
- 1段戻す
- 段階 0〜4

例:
1. 妻が待つ。
2. 妻も母も待つ。
3. 妻も母の父の母も待つ。
4. 妻も父の母の父の母の父も待つ。
5. 妻も子の父の母の子の母の父の子も待つ。

各段階は必ず前段階より長くなり、同じ文型の主体・述語を維持します。怪文度フィルタとは独立して動作します。

データ: `data/growth-engine-v10.json`
設計: `docs/STEPWISE_GROWTH_V10.md`
