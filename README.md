# 怪文回文メーカー

AI APIを使わず、回文制約と日本語の構文パターンを組み合わせて「意味は通るのに少し怪しい」回文を生成する試作プロジェクトです。

### 再帰DNA

母・父・子は読み自体が回文です。これを

`Xの + 回文名詞句 + のX`

で包むと、自然な親族名詞句のまま回文性を保てます。

- 母の父の母
- 父の母の父
- 母の子の母
- 父の母の父の母の父

これを自然文フレームへ挿入します。

- 確かに、母の父の母に貸した。
- 妻も母の父の母も待つ。
- ルイも母の母もいる。
- タミも母の子の母も見た。

完成文1,080件を保存しているわけではなく、**90名詞句 × 12文型**からその場で生成します。

## v0.9 逆語ペア辞書

自然文DNAの中核を `data/reverse-lexeme-pairs-v09.json` に分離しました。

基本形は **LEFT + 一文字助詞 + reverse(LEFT)** です。ただし、回文になる助詞を機械的に全部使うのではなく、日本語として自然な助詞だけをホワイトリスト登録します。

現在:
- 逆語ペア 30組
- 検証済み助詞バリアント 103文

例:
- 妻が待つ / 妻を待つ
- 魚が追う / 魚を追う
- 大使が敷いた
- 大佐が裂いた
- タイヤを焼いた
- タイツが付いた
- 対価を書いた
- ダンスが済んだ

公開UIには「逆語ペア」ボタンを追加しました。

## v0.10 段階的長文化

従来の「長文DNA」は指定深度以下を全部混ぜて抽選していたため、長文化を指定しても短文が出る問題がありました。

v0.10では長文化を独立した成長操作に変更しました。

- 短文から開始
- 1段伸ばす
- 同じ段階で別案
- 1段戻す
- 段階 0〜4

例:
1. 妻が待つ。
2. 妻も母も待つ。
3. 妻も母の父の母も待つ。
4. 妻も父の母の父の母の父も待つ。
5. 妻も子の父の母の子の母の父の子も待つ。

各段階は必ず前段階より長くなり、同じ文型の主体・述語を維持します。怪文度フィルタとは独立して動作します。

データ: `data/growth-engine-v10.json`
設計: `docs/STEPWISE_GROWTH_V10.md`


## v0.12 物語型長文化

長文化を2系統に分けました。

1. **構文型**  
   「妻が待つ」→「妻も母も待つ」→「妻も母の父の母も待つ」のように、主題・述語を固定して中心関係を伸ばします。

2. **物語型**  
   全文を個別監査し、情報を1種類ずつ足します。

例:
- 松茸摘み、見つけた妻。
- 松茸摘みに来て、奇跡的に見つけた妻。
- この松茸摘みに来て、奇跡的に見つけた妻の子。
- 確かに、この松茸摘みに来て、奇跡的に見つけた妻の子に貸した。

物語型は現在8系統25段階。各段階は完全回文かつ前段より必ず長いことをCIで検証します。


## v0.13 50かな級の物語長文化

物語型の後半に「受け手の人物関係を1層ずつ深くする」段階を追加しました。

松茸系では、

- 確かに貸した。
- 確かに、松茸摘み、見つけた妻に貸した。
- 確かに、松茸摘みに来て、奇跡的に見つけた妻に貸した。
- 確かに、この松茸摘みに来て、奇跡的に見つけた妻の子に貸した。
- 確かに、母のこの…妻の子の母に貸した。
- 確かに、父の母のこの…妻の子の母の父に貸した。
- 確かに、母の父の母のこの…妻の子の母の父の母に貸した。

まで段階的に伸び、最長 **51かな** です。

述語と中心人物を保持したまま、名詞句の関係だけを深くするため、単純な回文語の数珠つなぎとは分離しています。


## v0.14 場所・理由・状況を足す

物語型長文化を「関係」だけでなく、意味上の追加情報で分類しました。

- 場所: 庭のワニ → この庭のワニの子 → この庭の滝の北のワニの子
- 理由: ダイセの母のせいだ → ダイセの庭のワニのせいだ → 場所や関係を追加
- 状況: 旦那、ナナなんだ → 旦那、庭のワニなんだ → 正体を詳しくする

現在:
- 物語型 11系統
- 64段階
- L1 9系統
- L2 2系統

第二層でも物語型長文化を利用でき、選択欄には [場所] [理由] [状況] などのdimensionを表示します。

## v0.18 文レベル長文化

完成済みの完全回文文を、その場で外側から包める汎用wrapperを追加しました。

- 大樹と「P」と聞いた
- タミと「P」と見た
- ルミと「P」と見る
- 対価と「P」と書いた

Pが完全回文なら、包んだ全文も必ず完全回文です。

公開UIでは「文を1段包む」「1段ほどく」を追加し、同じ文を何段でも伸ばせます。引用符は深度に応じて「」と『』を交互に使います。

事前登録した引用・伝聞系では最長87かなまで検証済みですが、汎用wrapper自体には固定の段数上限を設けていません。

## v0.20 セリフ内外の名詞重複回避

sentence wrapper に `outer_lexemes` を持たせ、内側の文に同じ名詞が出ている外枠を候補から自動除外します。

例:
- 内側に「タミ」がある → タミ系外枠を除外
- 一度「大樹と…」で包んだ → 以後、大樹系外枠を除外

公開UIの既定は「自動（名詞重複回避）」です。

外枠は11種類へ増加し、発言・伝聞・陳述・質問・語り・決定・判断・解釈・記述・理由化・記録同定を用意しました。

固定長文4系統も重複回避規則で再生成し、最長固定例は **131かな**。100かな基準も131かなへ更新されています。
