# 怪文回文メーカー

AI APIを使わず、回文制約と日本語の構文パターンを組み合わせて「意味は通るのに少し怪しい」回文を生成する試作プロジェクトです。

## v0.7

第一層を、単なる短い回文集から **助詞を含む自然な日本語文のDNA** へ拡張しました。

- **L1 第一層: 標準日本語 150件**
- **L2 第二層: 意味の通る怪文 30件**
- **L3 第三層: 実験文 83件**
- 合計 **263件**
- 生成DNA **64規則**
- かな表記での完全回文検証: **263 / 263**

### v0.7の主力構造

名詞の読みと、逆向きに読んだ動詞・形容詞を対応させ、その間に助詞を置きます。

- 妻が待つ / 妻を待つ / 妻と待つ
- 須田が出す / 須田に出す
- タミが見た / タミを見た
- ルミが見る / ルミを見る
- ルネが寝る
- タキが来た
- タキオが起きた
- ルイがいる / ルイといる
- 鯛がいた
- 靴が付く / 靴に付く / 靴を突く
- イルカが軽い
- 椅子屋が安い
- 井川が若い
- 竹屋が焼けた
- 蓼が出た

さらに、鏡面に同じ助詞を置くことで長文化できます。

- 妻も母も待つ。
- タミも母も見た。
- ルイも父もいる。
- 妻とナナと待つ。

### 二軸評価

v0.7から、層とは別に

- `japanese_quality`: 日本語としての質 A/B/C
- `weirdness`: 怪文度 1〜5

を持たせています。
