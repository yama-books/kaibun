# 怪文回文メーカー

AI APIを使わず、回文制約と日本語の構文パターンを組み合わせて「意味は通るのに少し怪しい」回文を生成する試作プロジェクトです。

## v0.6

日本語としての質を三層に分け、第一層を重点的に増補しています。

- **L1 第一層: 標準日本語 105件**
- **L2 第二層: 意味の通る怪文 25件**
- **L3 第三層: 実験文 83件**
- 合計 **213件**
- かな表記での完全回文検証: **213 / 213**

さらに、固定例文の水増しを避けるため、**26種類の生成DNA規則**を定義しました。自由な文字代入はせず、人間が日本語として確認した語彙スロットだけを許可するホワイトリスト方式です。

### L1で追加した主な構造

- 私、貸したわ / 消したわ / 押したわ / 出したわ
- 私、混ぜましたわ / 待ちましたわ / 曲げましたわ
- 買うか / 貸すか / 書くか / 勝つか
- 泣くな / 鳴るな
- 読むよ / 寄るよ / 呼ぶよ
- 寝るね / 寝たね
- 飲むの / 乗るの
- 沸くわ / 割るわ
- 仲間かな / 中身かな
- 値段だね / 素手です / 誰だ / ダメだ

### 層の考え方

- **L1**: 助詞・活用・語順を含め、通常の独立文として自然。
- **L2**: 「旦那、キキなんだ。」のような口語省略や、「確かに、庭のワニに貸した。」のような意味上の異常を許す。
- **L3**: 「タミ、母見た。」などの電文調・舞台指示調。標準生成には混ぜない。
