# 怪文回文メーカー

AI APIを使わず、回文制約と日本語の構文パターンを組み合わせて「意味は通るのに少し怪しい」回文を生成する試作プロジェクトです。

### 再帰DNA

母・父・子は読み自体が回文です。これを

`Xの + 回文名詞句 + のX`

で包むと、自然な親族名詞句のまま回文性を保てます。

- 母の父の母
- 父の母の父
- 母の子の母
- 父の母の父の母の父

これを自然文フレームへ挿入します。

- 確かに、母の父の母に貸した。
- 妻も母の父の母も待つ。
- ルイも母の母もいる。
- タミも母の子の母も見た。

完成文1,080件を保存しているわけではなく、**90名詞句 × 12文型**からその場で生成します。

## v0.10 段階的長文化

従来の「長文DNA」は指定深度以下を全部混ぜて抽選していたため、長文化を指定しても短文が出る問題がありました。

v0.10では長文化を独立した成長操作に変更しました。

- 短文から開始
- 1段伸ばす
- 同じ段階で別案
- 1段戻す
- 段階 0〜4

例:
1. 妻が待つ。
2. 妻も母も待つ。
3. 妻も母の父の母も待つ。
4. 妻も父の母の父の母の父も待つ。
5. 妻も子の父の母の子の母の父の子も待つ。

各段階は必ず前段階より長くなり、同じ文型の主体・述語を維持します。怪文度フィルタとは独立して動作します。

データ: `data/growth-engine-v10.json`
設計: `docs/STEPWISE_GROWTH_V10.md`


## v0.12 物語型長文化

長文化を2系統に分けました。

1. **構文型**  
   「妻が待つ」→「妻も母も待つ」→「妻も母の父の母も待つ」のように、主題・述語を固定して中心関係を伸ばします。

2. **物語型**  
   全文を個別監査し、情報を1種類ずつ足します。

例:
- 松茸摘み、見つけた妻。
- 松茸摘みに来て、奇跡的に見つけた妻。
- この松茸摘みに来て、奇跡的に見つけた妻の子。
- 確かに、この松茸摘みに来て、奇跡的に見つけた妻の子に貸した。

物語型は現在8系統25段階。各段階は完全回文かつ前段より必ず長いことをCIで検証します。

## v0.20 セリフ内外の名詞重複回避

sentence wrapper に `outer_lexemes` を持たせ、内側の文に同じ名詞が出ている外枠を候補から自動除外します。

例:
- 内側に「タミ」がある → タミ系外枠を除外
- 一度「大樹と…」で包んだ → 以後、大樹系外枠を除外

公開UIの既定は「自動（名詞重複回避）」です。

外枠は11種類へ増加し、発言・伝聞・陳述・質問・語り・決定・判断・解釈・記述・理由化・記録同定を用意しました。

固定長文4系統も重複回避規則で再生成し、最長固定例は **131かな**。100かな基準も131かなへ更新されています。

## v0.25 境界ずらしDNA

宝船の回文歌「長き夜の…」を参考に、左右の語を一対一で対応させない生成方式を追加しました。

原理:
- 回文制約はかな列に課す
- 語境界は左右でずらしてよい
- 鏡像する音列が別の品詞・統語役割を持ってよい
- 「の・に・も」を助詞ヒンジとして使う
- 完成文全体の文法・意味で採否する

例:
- 確かにこの庭のワニの子に貸した。
- タミも今朝のこのナナの子の酒も見た。
- ダイセのこの庭のワニの子のせいだ。
- 旦那、この庭のワニの子なんだ。

公開UIに「継ぎ目型DNA」ボタンを追加しました。
